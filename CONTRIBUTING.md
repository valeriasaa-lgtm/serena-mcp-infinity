# Contributing to Serena MCP ◆

Thank you for contributing!

## Ground rules
- Keep it clean: no secrets, no personal data in code.
- Multi-voice (MVP): contribute voices via modular agents.
- Tests/docs: add an example when you add a model/prompt.

## Workflow
1. Fork & create a branch
2. Add your change
3. Add an example under `examples/`
4. Open a PR
